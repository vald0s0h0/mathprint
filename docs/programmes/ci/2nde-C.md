- **Référentiel système** : programme `ci`, niveau `2nde`, série `ci-C`
- **Volume** : 5 h par semaine, 32 semaines
- **Contenu** : 15 leçons, 103 habiletés, 250 contenus
- **Progression 2024-2025** : 125 h de leçons, + 15 h de régulation (1 h après chaque leçon) + 10 h de révisions
- **ID d’une compétence** : `CI-2023-MATH-2NDE-C-` suivi du code, par exemple `CI-2023-MATH-2NDE-C-A1.1`
- **Une ligne = une compétence de la plateforme** : un contenu officiel, précédé du verbe de son habileté, dans l’ordre du programme

Légende : `≡` leçon identique dans l’autre série de la même filière (avec son code là-bas), `≈ … (85 %)` leçon proche, part de contenus communs ; différences dans [chevauchements.md](chevauchements.md).
