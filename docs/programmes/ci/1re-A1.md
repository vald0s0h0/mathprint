# Mathématiques — Première A1 (Côte d’Ivoire)

- **Source** : [07. Prog Éduct MATHS 1A1 CND 0923.pdf](https://dpfc-ci.net/dpfc/programmes/maths/07.%20Prog%20%C3%89duct%20MATHS%201A1%20CND%200923.pdf) (DPFC, CND 09/2023), corps du programme p. 9–14
- **Référentiel système** : programme `ci`, niveau `1re`, série `ci-A1`
- **Volume** : 4 h par semaine, 32 semaines
- **Contenu** : 7 leçons, 44 habiletés, 111 contenus
- **Progression 2024-2025** : 105 h de leçons, + 7 h de régulation (1 h après chaque leçon) + 8 h de révisions
- **ID d’une compétence** : `CI-2023-MATH-1RE-A1-` suivi du code, par exemple `CI-2023-MATH-1RE-A1-A1.1`
- **Une ligne = une compétence de la plateforme** : un contenu officiel, précédé du verbe de son habileté, dans l’ordre du programme

Légende : `≡` leçon identique dans l’autre série de la même filière (avec son code là-bas), `≈ … (85 %)` leçon proche, part de contenus communs ; différences dans [chevauchements.md](chevauchements.md).

## Compétence 1 — Traiter une situation relative aux calculs algébriques et aux fonctions
