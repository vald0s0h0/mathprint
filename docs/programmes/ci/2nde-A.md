# Mathématiques — Seconde A (Côte d’Ivoire)

- **Source** : [05. Prog Éduct MATHS 2A CND 0923.pdf](https://dpfc-ci.net/dpfc/programmes/maths/05.%20Prog%20%C3%89duct%20MATHS%202A%20CND%200923.pdf) (DPFC, CND 09/2023), corps du programme p. 8–14
- **Référentiel système** : programme `ci`, niveau `2nde`, série `ci-A`
- **Volume** : 3 h par semaine, 32 semaines
- **Contenu** : 8 leçons, 50 habiletés, 109 contenus
- **Progression 2024-2025** : 76 h de leçons, + 8 h de régulation (1 h après chaque leçon) + 6 h de révisions
- **ID d’une compétence** : `CI-2023-MATH-2NDE-A-` suivi du code, par exemple `CI-2023-MATH-2NDE-A-A1.1`
- **Une ligne = une compétence de la plateforme** : un contenu officiel, précédé du verbe de son habileté, dans l’ordre du programme

Légende : `≡` leçon identique dans l’autre série de la même filière (avec son code là-bas), `≈ … (85 %)` leçon proche, part de contenus communs ; différences dans [chevauchements.md](chevauchements.md).
