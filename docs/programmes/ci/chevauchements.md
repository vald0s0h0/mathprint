# Chevauchements entre séries

Comparaison item par item (habileté + contenu) des leçons de même titre, au même niveau. Le collège n’a pas de série. En Seconde, la série D n’existe pas : les élèves de 1re D viennent de 2nde C, ceux de 1re A1/A2 de 2nde A.

Les leçons de même titre entre filières littéraire (A, A1, A2) et scientifique (C, D) ont des contenus distincts (0 à 28 % en commun) : elles ne sont comparées qu’au sein de leur filière.

Parcours : **2nde A → 1re A1 / 1re A2 → Tle A1 / Tle A2** ; **2nde C → 1re C / 1re D → Tle C / Tle D**.
